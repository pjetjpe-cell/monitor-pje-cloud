# /pje-consulta

Antes: leia `.agent/rules/gav-esteira.md` e siga
`.claude/skills/pje-consulta/SKILL.md` inteiro. **Somente leitura**: não
peticione, não junte documento, não altere cadastro.

1. Abra o PJe do TJPE (1º grau) no navegador já logado pelo usuário. Login,
   certificado ou token são com o usuário — peça e espere.
2. Busque por advogado (o informado; sem nome, pergunte), filtre Ipojuca.
3. Para cada processo: número, partes, última movimentação e data.
4. Diga quais estão desatualizados segundo o critério da skill.
