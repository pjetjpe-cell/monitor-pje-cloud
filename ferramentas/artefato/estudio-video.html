Prompt para o Claude Code

Montado a partir do briefing e do storyboard. Cole numa sessão do Claude Code aberta na pasta do estúdio (Remotion ou HyperFrames).

Receitas FFmpeg

Troque os nomes dos arquivos e os comandos se ajustam. Instale com winget install Gyan.FFmpeg.

Mentalidade

  • Claude é o diretor.
  • /watch são os olhos: lê frames e transcrição.
  • Remotion / HyperFrames são as mãos: vídeo em código, sempre editável.
  • Higgsfield / Google Flow são a imaginação: imagem e vídeo gerados.

Fluxo padrão

  1. Transcrever palavra por palavra com tempos (faster-whisper, grátis). Corrigir nomes ("Cloud" → "Claude").
  2. Cortar tempo morto: silêncios e erros.
  3. Extrair frames (/watch) para saber a posição do rosto e do cenário.
  4. Storyboard numerado (gancho → conteúdo → CTA) e aprovação antes de renderizar.
  5. Render e loop de verificação: o Claude critica os próprios frames e corrige. Saída MP4 16:9 e/ou 9:16.

Regras de ouro do prompt

  • Referência vale mais que descrição. Pode ser só de ritmo ou BPM.
  • Estilo limpo "Apple" evita cara de IA.
  • Diga quando cada elemento entra: "quando eu disser X, mostre o logo de X".
  • Feche com: "diretrizes gerais — tem liberdade criativa para melhorar".
  • Reserve um terço livre para o PiP. Prints reais valem mais que recriações.
  • Esforço médio já basta. Atualize a skill de estilo após cada projeto. Defina orçamento de créditos.

Instalação no Windows

Higgsfield

  • MCP: https://mcp.higgsfield.ai/mcp (OAuth, sem chave). Claude → Personalizar → Conectores → Higgsfield.
  • Produção realista: assets (produto, personagem, locais, figurino) → shotlist com prefixo de estilo fixo → gerar cena a cena e montar os segundos bons.
  • Rosto consistente: ficha de 3 painéis, fundo neutro, salvar como element. Keyframe importa mais que prompt.
  • Esconder cortes: match de ação, wipe em primeiro plano, som puxando o plano.
  • API pré-paga: Kling 3.0 US$ 0,20/s, Seedance 2.5 US$ 0,14/s.
  • Golpe: "ilimitado grátis com link secreto" é isca. Créditos legítimos vêm dos posts oficiais da @higgsfield no X.
